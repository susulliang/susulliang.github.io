About CryptoMatrix

CryptoMatrix is a secure encryption tool that transforms your text and images into a printable 2D dot map format. The encrypted data can be stored as either an image or as base64 text.

Key Features:

  • AES-256 encryption for military-grade security
  • Error correction codes (ECC) for reliable scanning
  • Print and scan friendly format
  • Support for both images and base64 text transmission

How It Works:

  1. Enter your user key (shared for encryption and decryption)
  2. On the Encrypt tab, input text and/or upload an image
  3. Download the dot map image or copy the base64 text
  4. On the Decrypt tab, upload the image or paste the base64 text
  5. Enter your user key to decrypt and retrieve your data
